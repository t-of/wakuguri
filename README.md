# わくぐり — 回る輪のすき間を通す

回っている輪のすき間を、玉がくぐり抜けるようにタップで撃ち出す。玉は輪を二度横切るので、入るときと出るときの両方ですき間が来る瞬間を読む。全 12 ステージ。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/wakuguri/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

1. 画面をタップすると、下の玉がまっすぐ上へ飛ぶ。
2. 輪の線に当たったら失敗。すき間を通れば進める。玉は輪を入るときと出るときの 2 回横切る。
3. いちばん上まで届けばステージクリア。何度でもすぐやり直せる。

- 全 12 ステージ。クリアすると次のステージが開く。記録はステージごとの「いちばん少ない挑戦回数」。
- PC ではクリックかスペースキーで撃てる。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
node test.mjs                 # 決まりごとのテスト（当たり判定・保存・ステージの「通れる割合」）
```

- 画面に触らない決まりごと（ステージの数字・玉と輪の動き・当たり判定・保存）は `logic.js`、画面と音は `main.js`。
- ステージを変えたら `node test.mjs` を回す。撃つ時刻を 0〜20 秒の間で 1/120 秒おきに全部試し、ゴールに届く割合を出して、
  0% のステージがないこと、番号が上がるほど下がること（1 は 30〜45%、12 は 3〜6%）を確かめる。
- 保存: `wakuguri.settings`（`{ v: 1, sound }`）、`wakuguri.progress`（`{ v: 1, best: { ステージ番号: 最少の挑戦回数 } }`）。
